# 地震詳細ページの震度セクション冗長分割の解消

- 状態: **案 A 確定**（2026-08-27 ご主人裁定）
- 対象: `display/frontend/src/lib/instrument-layout.ts`（`paginateAreas`）・`display/frontend/src/components/LatestQuakeCard.svelte`（描画側）
- 起源: 2026-08-27 ご主人・実機観測（scenario 4/7 の gate スクショでも再現）

## 1. 症状

待機画面の地震情報カード（観測震度 詳細）で、次の冗長な構成が出る。

```
震度6弱
その他　宮崎市
震度6弱
その他（続き）　日南市
震度5強
その他　都城市
震度5強
その他（続き）　延岡市
```

同一震度・同一県グループ（ここでは pref=null の「その他」）が都市 1 件ごとに分断され、
そのたびに震度見出しと県名が繰り返される。「（続き）」は本来ページをまたぐ継続の印なのに、
断片が**同一ページに並んで見えて**しまい、見出しの繰り返しだけが残る。

## 2. 根因（コード読了済み）

`paginateAreas` は本文予算 `budget`（1 行 = `AVG_CITIES_PER_LINE` = 4 件換算、カード本文高から
`cityBudgetFromArea` で導出）から、セクション見出し 1 行分 `DETAIL_SECTION_HEADER_WEIGHT`（= 4）を
引いた `sectionContentBudget` で県グループを詰める。

- 本文が 1 行分（budget = 4）のとき `4 − 4 = 0` → `Math.max(1, …)` の下限 **1** に張り付く
- 予算 1 では 2 都市の県グループですら「単独県がバジェット超」の分割経路に入り、
  **都市 1 件 = 1 セクション断片**へ degenerate する
- 分断された断片は `allowCrossIntensity` の詰め直しで同一表示ページに同居し得るため、
  「ページまたぎの継続表示」という設計意図が視覚上失われる

## 3. 裁定結果

### 案 A: 描画側で同一ページ内の同震度断片を結合する

`LatestQuakeCard` の描画直前に、同一ページ内で隣接する同 `rank`/`intensity` のセクション断片を
1 セクションへ結合し、同一 pref の連続 prefGroup（continuation 含む）は cities を連結して
1 ブロックにする。ページ境界をまたぐ本来の「（続き）」表示は不変。

- 利点: 分割アルゴリズム（実測ベースの容量判定）に手を入れないため、ページ数・改ページ位置が
  一切変わらない。表示の冗長だけが消える
- 欠点: 描画側に結合ロジックが 1 枚増える

ご主人裁定により、案 A を採用する。分割アルゴリズムとページ境界は変更せず、
`LatestQuakeCard` の描画直前に純関数で結合する。これにより、同一ページ内の重複した
震度見出しと県ブロックだけを除去し、ページ境界をまたぐ本来の「（続き）」表示を保つ。

## 4. 受入条件（機械検証）

- 再現 fixture（宮崎市・日南市 = 6弱 / 都城市・延岡市 = 5強、pref なし、1 行予算）で、
  同一ページに同震度見出しが 2 回以上出ないこと（unit test）
- ページをまたぐ大県分断の既存テスト（instrument-layout.test.ts の continuation 系）が不変で緑
- `npm --prefix display test` 全緑・Chrome gate `--report` 18/18 match 維持
- scenario 4 / 1512×982 の gate スクショ目視で、震度見出しが震度ごとに 1 回のみ
