# 通知音の設計規範（sound design system）

通知音 5 段階（`critical` / `warning` / `normal` / `info` / `cancel`）の作り方を固定する。音源は外部のフリー素材ではなく、`scripts/render-sounds.mjs` が本書の規則から生成する。2026-09-14 作者裁定（聴き比べ 6 巡で確定）。

## 原則

- **同じ楽器で鳴らす**: 全段階が同じ音色（サイン波＋第 2 倍音 0.25、立ち上がり 5 ms、指数減衰、末尾 30 ms リリース）。重大度は音色ではなく**回数・高さ・和音・減衰**で表す
- **単音か和音だけ**: メロディは作らない。和音は短三和音（不穏さ）に限る
- **残響は打音ごとに揃える**: 複数打は各打音を同じ減衰で最後まで鳴らし、重ねて合成する（前の打音を次の打音で切らない）
- **既存の報知音を模倣しない**: NHK のチャイムや気象庁の緊急地震速報報知音に意図的に寄せない
- **音量は 5 本共通のピーク基準**（-3 dBFS）で揃え、段階間の差は `gain` で持つ

## 段階表

| level | 形 | 音 | 発音時刻（秒） | decay | gain | 意図 |
|---|---|---|---|---|---|---|
| info | 単音 1 回 | A4（440 Hz） | 0 | 9 | 0.5 | 気づく程度 |
| normal | 単音 1 回 | C5（523 Hz） | 0 | 9 | 0.8 | 標準の合図 |
| warning | 短三和音 2 回 | C5-E♭5-G5 | 0, 0.12 | 9 | 0.9 | 注意を引く |
| critical | 短三和音 3 回、尾なし | C6-E♭6-G6 | 0, 0.14, 0.28 | 14 | 1.0 | 最上位。速く切れる |
| cancel | 単音の下行 2 音 | G5 → C5 | 0, 0.30 | 8 | 0.6 | 解除は下がる |

- 高さの関係: info（A4）< normal（C5）= warning の根音 < critical（1 オクターブ上）。normal の単音 C に warning の短三和音が乗る関係
- 長さは残響込みで 0.56〜0.93 秒。`decay` を上げると短く、下げると長くなる

## 生成と配置

```bash
node scripts/render-sounds.mjs            # assets/sounds/<level>.wav を上書き
node scripts/render-sounds.mjs /tmp/out   # 聴き比べ用
```

- 出力は 44.1 kHz・16 bit・mono の WAV。`assets/sounds/` は npm パッケージに含まれ、`src/engine/notification/sound-player.ts` が `<level>.mp3` → `<level>.wav` の順で探す。Linux の再生は `ffplay` → `paplay` → `aplay` の順で試し、起動時の音声 probe も同じ列を無音 WAV で辿る（バナーの `音声: <player> OK` は実際に成功した player。Issue #20）
- 規則を変えるときは本書の表と `MOTIFS` を同時に直し、生成し直して commit する。生成物を手で編集しない

## 分野別根音表 v1（新築の通知 intent 用。2026-09-14 規則確定、2026-09-15 裁定 B、2026-09-17 統合）

旧築の 5 段階 `playSound(level)` は上の段階表のまま据え置く。新築（`reconstruction/`）の通知 intent（P0 spec §6.2）は分野（domain）を持ち、`channel:"sound"` の音源を **分野 × 段階** で選ぶ。分野の根音は危険度が高いほど高い音域にする。

1. **分野 → 根音**

| 分野 | 根音 | Hz |
|---|---|---:|
| 気象 | C4 | 261.63 |
| 火山 | G4 | 392.00 |
| 地震・EEW | C5 | 523.25 |
| 津波 | F5 | 698.46 |

2. **段階 → 形**（根音からの半音。全分野共通、津波だけ和音の質が違う）

| level | 形 | 半音 | 発音時刻（秒） | decay | gain |
|---|---|---|---|---|---|
| info | 単音 | −3 | 0 | 9 | 0.5 |
| normal | 単音 | 0 | 0 | 9 | 0.8 |
| warning | 和音 ×2 | 短三和音 0,3,7（津波は 0,1,6） | 0, 0.12 | 9 | 0.9 |
| critical | 和音 ×3、尾なし | 1 オクターブ上 12,15,19（津波は 12,13,18） | 0, 0.14, 0.28 | 14 | 1.0 |
| cancel | 単音の下行 | 7 → 0 | 0, 0.30 | 8 | 0.6 |

- 音色は上の段階表と同じ（サイン波＋第 2 倍音 0.25、立ち上がり 5ms、指数減衰、末尾 30ms リリース）。複数打は各打音を同じ減衰で鳴らし切って加算する。音量は全ファイル共通のピーク基準で −3 dBFS
- training／test は鳴らさない（P0 spec §5.1 の開始案、P2 計画 D7=A）
- 聴き比べの経緯: 分野の根音は最初「津波 C4・気象 F5」だったが、津波が 4 分野で最も危険度が高いので丸ごと入れ替えた。津波の不協和音は 6 種（0,1,6／0,1／0,6／0,3,6／0,4,8／0,3,7,8）を比較して 0,1,6 を採用
- 新築での実装（P2 契約 A7 notification の範囲）: 資産は `assets/sounds/<domain>-<level>.wav` の 20 本。レンダラは `scripts/render-sounds.mjs` の `MOTIFS` を「根音表 × 段階形」の 2 表に分ける。分野が決まらない intent は作らない（fallback 音源を置かない）。テストは分野→ファイル名の解決の契約境界だけ。Linux の再生列は旧築と同じ `linuxPlayersFor()`（Issue #20）
