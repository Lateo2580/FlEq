主な機能

FEATURES

WS

リアルタイム受信

WebSocket による自動再接続と複線接続に対応

EEW

EEW 同時追跡

差分表記とログ記録

WX

気象電文

警報、注意報、熱中症警戒アラート、洪水予報などに v3.0.0 で対応

NOTIFY

デスクトップ通知

カテゴリ別の通知 ON/OFF と通知音を設定

TUNE

カスタマイズ

filter で電文を絞り、template で表示書式を整える。夜間モード (night) と REPL で実行中も調整可能

ARM

低メモリ対応

Raspberry Pi など ARM デバイスでも動作

インストール

GETTING STARTED

1

グローバルにインストール

npm install -g @sayue_ltr/fleq クリップボード API に対応していません
2

初期設定

対話形式で API キーと受信区分をまとめて設定できます

fleq init クリップボード API に対応していません
3

起動

fleq クリップボード API に対応していません

前提条件

  • 利用: Node.js 18 以上
  • source checkout での開発・ビルド: Node.js 20.19 以上
  • dmdata.jp のアカウントと API キーが必要です
  • API キーには socket.start 権限と、受信区分に対応する telegram.get.* 権限を付与してください
  • 情報を受信するには dmdata.jp の有料契約が必要です
